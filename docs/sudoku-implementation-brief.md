# Sudoku web implementation brief

Started 2026-11-04 after the user's Resume instruction. The ZIP describes Android migration and references an unavailable Sudoku implementation. This release is independent classic 9×9 Sudoku, without app puzzle-bank, generator or rating parity claims.

- Each row, column and 3×3 box must contain digits 1–9 once. Generate a complete board using seeded randomized search, remove clues only when an exact bounded counter proves one solution. If uniqueness search exhausts its budget, keep the clue. Generation runs in a cancellable worker. Never publish a puzzle of unproven uniqueness.
- Easy/Medium/Hard initially target 42/35/29 clues. Disclose that these are clue-density settings, not human-technique ratings; display actual clue count. Do not claim fewer clues always means a harder puzzle. A website daily uses a date seed with explicit level; no unique-answer claim without validation, no app parity.
- Keyboard digits/Delete/arrows, labelled cells, givens protected, notes mode and visible conflicts distinguishable beyond colour. Board can scroll on narrow screens to preserve usable cells. Undo restores values and notes. Save/continue validates givens, editable values, notes and puzzle identity. Completion requires a legal full grid and unchanged givens.
- Hints first explain real naked/hidden singles from current candidates. If no supported deduction is available, say so; offer an explicitly assisted answer reveal rather than inventing logic. Conflicting entries should be corrected first. No ad gate, timer pressure or forced mistake limit.
- Records: completed and assisted/unassisted solves, best active time where accurately measured, and local daily streak. Do not use wall-clock tab absence as active solving time. Stable IDs prevent duplicate results; blocked storage remains playable.
- Original worked guide uses fixtures executed against the same engine. Indexable setup/guide and noindex game route only after full UI, generator/solver/invalid/history tests, browser completion/save/keyboard/phone checks, lint/build/static checks and exact live publication verification. Preserve seven existing games and their storage keys.
