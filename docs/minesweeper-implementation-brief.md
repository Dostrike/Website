# Minesweeper web implementation brief

Prepared 2026-11-04 after Sudoku publication, from the supplied new-games.md. Independent implementation; no Android generator/seed/rating parity claim.

- Beginner9×9/10, Intermediate16×16/40, Expert16-wide×30-tall/99 for portrait, bounded custom dimensions/mines. Explicit displayed dimensions and counts. First reveal excludes its cell and neighbours, opening a zero area; do not place mines until that first reveal is known.
- No-guess on by default: a solver that sees only revealed numbers/known flags must demonstrate a full safe completion from that first cell using single-number and subset deductions. It must not consult the mine map to choose moves. The map is used only to evaluate reveals. Generate/retry in a cancellable worker with a finite attempt/node/time budget. If no board is proven in budget, report failure/retry; never silently publish a guessing board under a no-guess label. Test independent deduction certificates and edge/custom feasibility.
- Keyboard reveal/flag actions, touch Dig/Flag toggle and contextual accessible controls. Implement chording only when flag count matches the number; incorrect flags can cause a loss and this must be explained. Flood reveal must be iterative, bounded and respect flags. Panning/zoom or scrolling keeps large boards usable, with visible coordinates/status/flags-left and non-colour number/flag/mine labels. No game information hidden behind decorative art.
- Free explicitly assisted safe reveal, optional single second chance undoing the losing action, separate assisted/unassisted records. Preserve pre-action state for multi-cell chord losses. All assistance stays marked after undo/reload. Stable result IDs and valid browser saves; paused/hidden-page time excluded if best-time records are included, otherwise omit timing claims.
- Daily Intermediate no-guess uses fixed date seed and a fixed disclosed first reveal, so players see the same board. If the opening cell is player-chosen for normal games, seed and first reveal jointly identify that board. Verify generation/determinism, solver proof, game win/loss, flooding, chord/flags, assistance/history/save and daily boundary records before public routes.
- Original worked guide from actual verified fixtures: one-number all-safe/all-mine deductions, subset deduction, wrong-flag chord risk, what the no-guess certification covers. Setup/guide indexable; runtime noindex/excluded. Lint/build/static/browser/full-game/live checks and truthful metadata. Preserve eight published games; no backend or account changes.
