# Slide Merge web implementation brief

Started2026-11-04 while the goal remains active, after verified Minesweeper and factual-content releases. The Android game is referenced but no engine is supplied. Implement original classic4×4 number sliding; no app RNG/daily/feature parity promise.

Rules reference checked November4: original author's game manager https://github.com/gabrielecirulli/2048/blob/master/js/game_manager.js . Consulted for behavioural conventions, not copied code/assets: equal adjacent tiles merge once per move, merged values add to score, a changed board receives one2/4 tile with90/10 weighting,2048 is a milestone and continuing is optional. Use DoStrike's own implementation, design and seeded generator.

- Four directions compress rows/columns to the edge; each input tile merges at most once. No-op moves do not spawn, score, consume RNG or enter history. Start with two spawned tiles. Loss only when no slide/merge remains. Reaching2048 pauses with an explicit Continue option; continuing can exceed2048. A reached-target round is not later counted as a loss.
- Deterministic PRNG state follows valid moves. Replay/save validates seed and action sequence. Undo restores board, score, RNG and milestone state; repeating the same move after undo must produce the same spawn. Mark undo-assisted rounds honestly. Do not provide a reroll disguised as undo.
- Arrow/WASD or explicit direction buttons, touch swipes constrained to the board, legible numbers, non-colour labels, reduced-motion support and phone containment. Keyboard focus/control instructions and score/merge/result announcements. Preserve existing nine games/record keys.
- Website daily uses a date seed; same initial board/random stream, with subsequent board positions depending on moves. Full game, no unique-answer puzzle or guaranteed2048 claim. Browser-only score/largest-tile/target/completed-game records, assisted split and daily milestone streak; deduplicate first milestone and later game-over outcomes. No timer or ad gate.
- Original worked guide from fixtures:2,2,2,2 →4,4,0,0 with8 points;2,2,4,4 →4,8,0,0 with12; no cascading merge, all directions, no-op/RNG, keeping space versus corner heuristic without guaranteed strategy claims. Complete deterministic games and independent line reference checks before UI publication.
- Pure engine first; then saved-round/undo/result logic, playable UI, guide, metadata/sitemaps. Lint/build/static, keyboard/swipe/phone/browser complete-round/reload tests and exact live verification. Ads remain disabled; no backend/account changes.
